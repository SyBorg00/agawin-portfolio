# Portfolio — Next.js + Vercel

## Local setup
1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Customize
Edit `app/page.js` for your name, bio, projects, links, and email. Edit `app/globals.css` for the design.

## Deploy to Vercel
Push this folder to GitHub, then import the repository into Vercel. Vercel will detect Next.js automatically. No special build configuration is required.
